# N. Registrar decisões de arquitetura

- Status: Aceita
- Data: 2026-10-31

## Contexto

projeto de uma pessoa, que também é portfólio: decisões tomadas hoje precisam ser explicáveis depois, e o desenho (documento 1) não viaja com o código

## Decisão

registrar toda decisão estrutural em docs/adr/, formato Nygard, numeradas, imutáveis depois de aceitas

## Consequências

mudar decisão exige ADR nova (alinhado com o documento 1: "mudar uma delas depois exige um ADR novo"); custo pequeno de escrita a cada decisão
